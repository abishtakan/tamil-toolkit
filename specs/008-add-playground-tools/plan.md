# Implementation Plan: Additional Interactive Linguistic & Epigraphical Tools

**Branch**: `008-add-playground-tools` | **Date**: 2026-11-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/008-add-playground-tools/spec.md`

## Summary

Expand the Tamil Toolkit Playground with three high-impact, authentic linguistic utilities:
1. **Traditional Tamil Fractions & Epigraphical Symbol Explorer** (`SymbolsExplorer.tsx` in Public Tools)
2. **Tamil Letter & Uyirmei Morphological Decomposer** (`LetterAnalyzer.tsx` in Developer Tools)
3. **Tamil Unicode Text Normalizer & Anomaly Repair Tool** (`NormalizerTool.tsx` in Developer Tools)

All tools run 100% client-side via the compiled WebAssembly engine (`tamil-toolkit/web`), integrate with the bilingual dictionary (`i18n.ts`), and strictly follow the Basalt Granite / Palm Leaf design system.

---

## Technical Context

**Language/Version**: TypeScript 5.8+ / React 19 / Rust 1.85+ (WASM)

**Primary Dependencies**: `tamil-toolkit/web` (compiled WebAssembly), React 19, Tailwind CSS v4, Lucide React, Radix UI primitives

**Storage**: Browser LocalStorage (for theme and language preference only; zero user data stored)

**Testing**: Vitest (`pnpm --filter tamil-toolkit-playground test`)

**Target Platform**: Evergreen desktop & mobile browsers (offline-ready PWA)

**Project Type**: Web Application / Interactive Linguistic Workbench

**Performance Goals**: Sub-50ms real-time analysis latency, 60fps transitions, zero layout shift

**Constraints**: 100% client-side execution, offline-capable, WCAG AAA (15.8:1) body contrast and AA (5.7:1) secondary contrast, 1px hairline transitions, no bouncy scaling (`scale-105`)

---

## Constitution Check

*GATE: Passed before Phase 0 research. Re-checked post-design.*

- **Principle I (Rust Owns Linguistic Behavior)**: Verified. All fraction calculations, letter segmentations, uyirmei decompositions, and Unicode normalizations execute via `execute()` in `tamil-toolkit/web`. No client-side ad-hoc linguistic heuristics are written in TypeScript.
- **Principle II (Inspect Tamil by Scalars)**: Verified. Grapheme clusters and code points are inspected using exact Unicode hexadecimal scalar escapes (`U+0B85`, `U+11FC0` etc.).
- **Principle VII (Quality Gates)**: Verified. Automated tests in `mobile-ergonomics.test.ts` and component tests ensure design token integrity and WCAG conformance.
