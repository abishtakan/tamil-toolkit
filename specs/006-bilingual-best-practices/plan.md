# Implementation Plan: Bilingual Architecture & Internationalization Best Practices

**Branch**: `006-bilingual-best-practices` | **Date**: 2026-11-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/006-bilingual-best-practices/spec.md`

## Summary

Refactor the internationalization architecture in `playground/` to adhere to enterprise best practices:
1. Replace all scattered inline JSX ternaries (`language === "en" ? ... : ...`) with structured dictionary keys in `Translations`.
2. Introduce URL query parameter synchronization (`?lang=ta` / `?lang=en`) via `window.history.replaceState` for shareable links.
3. Update `document.documentElement.lang`, directional formatting, and document title dynamically.
4. Maintain strict 100% compile-time key parity between Tamil and English.

## Technical Context

**Language/Version**: TypeScript 5.8+, React 19, Vite 8, Tailwind CSS v4

**Performance Goals**: Instant locale switch (< 16ms, single frame), zero network latency
**Constraints**: 100% client-side execution (zero server calls, zero data leaks)
**Scale/Scope**: 9 interactive tools, 2 core locales (`ta`, `en`)
