# Implementation Plan: Automatic Legacy Tamil Encoding Detection (`detect_encoding`)

**Branch**: `003-codec-detection` | **Date**: 2026-11-05 | **Spec**: [specs/003-codec-detection/spec.md](file:///C:/Users/abish/Documents/dev/tamil-toolkit/specs/003-codec-detection/spec.md)

**Input**: Feature specification from `specs/003-codec-detection/spec.md`

## Summary

Implement an automatic encoding detection and auto-decode engine for legacy Tamil encodings (`bamini-v1`, `tscii-1.7-v1`, `tab-v1`, `tam-v1`, `anjal-v1`, `lt-tm-cid-v1`, `vanavil-avvaiyar-cid-v1`, and modern `utf-8`) in `crates/tamil-codec`, exposed via the unified dispatcher in `crates/tamil-toolkit` and multi-runtime bindings (Python, WebAssembly, Dart). Scoring leverages existing decode trie transitions, signature n-grams, and ASCII neutrality to reliably classify mixed English-Tamil documents within a sub-5-microsecond latency budget.

## Technical Context

**Language/Version**: Modern Stable Rust (MSRV 1.80+), Python 3.10+, Node.js 18+ (WASM), Dart 3.0+  
**Primary Dependencies**: None in `tamil-codec` (zero external dependencies); `serde`, `serde_json` in `tamil-toolkit` for serialization  
**Storage**: Static immutable byte/codepoint transition tables generated by `build.rs` or embedded in static memory  
**Testing**: `cargo test -p tamil-codec`, `cargo test -p tamil-toolkit --test codec_detection`, `just test-parity`  
**Target Platform**: Cross-platform (Linux, macOS, Windows, Web WebAssembly, iOS/Android Dart)  
**Project Type**: Core Rust systems library + FFI multi-runtime bindings  
**Performance Goals**: < 5 microseconds per detection for buffers up to 1KB in Rust benchmarks (SC-003); zero heap allocations during candidate scoring  
**Constraints**: Maximum inspection sample size of 4,096 bytes or code units; 0% false positive rate on plain English text (SC-002); >98% accuracy on test corpuses (SC-001)  
**Scale/Scope**: 7 legacy encoding profiles + modern UTF-8; 150+ golden vectors in `tests/golden/codec_detection.jsonl`

├── python/                     # PyO3 wrappers for detect_encoding & detect_and_decode

tests/

**Structure Decision**: Monorepo Rust workspace with sub-module `detection` inside `crates/tamil-codec` to keep scoring modular, zero-allocation, and distinct from encode/decode routines.
