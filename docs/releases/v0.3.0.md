## Compatibility and scope

- All 12 crates on crates.io, `tamil-toolkit` on npm, and `tamil-toolkit` on PyPI are slim `Apache-2.0` packages with zero embedded third-party dictionary bytes.
- Runtime `.tlpack` v2 dictionary packs are distributed separately via GitHub Releases (`lexicon-packs-0.2.0` `open` / `lexicon-packs-0.3.0` `full`), `tamil-toolkit lexicon pull`, Python `lexicon_download`, JS/WASM `LexiconPackClient`, and Dart `TamilLexiconPackManager`.
- The live Playground (`https://tamil-toolkit-playground.vercel.app`) serves `0.3.0` WASM and caches `.tlpack` v2 packs in browser `CacheStorage` (`tamil-toolkit-tlpack-v2`).
