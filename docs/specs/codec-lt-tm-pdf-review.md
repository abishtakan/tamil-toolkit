# 2003 Tamilmann PDF: LT-TM extraction review

This is a review ledger for the bounded LT-TM PDF extractor, not a complete
transcription. It lists every run decoded by the five spot-checked font faces.
The scalar column is the Rust codec's output; it is evidence to compare against
the rendered page, not an independent proof that each font mapping is correct.

## Source and coverage

- Source: 2003 Tamilmann *Tolkāppiyam* PDF; SHA-256 is recorded in
  [the LT-TM profile contract](codec-lt-tm.md).
- PDF pages: 351; text-showing operations: 24356.
- Decoded runs: 103; unsupported-font runs: 24253; decode errors: 0.
- Decoding is restricted to `LT-TM-Nehru`, `LT-TM-Nakkeran`,
  `LT-TM-Narmada`, `LT-TM-Nila,Bold`, and `LT-TM-Sindhu`, with only the
  six-uppercase-letter PDF subset prefix ignored.
- Independent PDFium text-page extraction contained all 103 raw CID sequences.
  This validates code capture, not Unicode mapping.
- Rendered pages 1, 3, 5, 6, 16, 17, 27, 40, 60, and 78 were sampled.
  The title and visible headings compared on those pages matched. This is not
  a full visual review of every decoded run.
